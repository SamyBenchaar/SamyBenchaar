## Featured projects

### 🧠 [AlphaAI](https://github.com/SamyBenchaar/Datathon2026): verifiable AI for investors
*Finalist, PolyFinances Datathon 2026 × National Bank × AWS. Built end to end in 36 hours with a team.*
A personalised financial-news filter that explains why each headline matters to a given investor's portfolio. Every figure in an explanation is traced to code-computed evidence, and a guardrail checks each generated sentence. Python/FastAPI on AWS Lambda + Bedrock (Claude), deterministic YAML rules engine, React front end.

### 🎮 [Brick by Brick](https://github.com/SamyBenchaar/Brick-by-Brick): multiplayer tactical RPG
Real-time, turn-based strategy game playable in the browser: map editor, lobbies, WebSocket-synchronised combat, and bot players using Dijkstra and BFS. Angular + NestJS + Socket.IO, deployed on AWS EC2, with unit tests and CI.

### 🗂️ [Tab Context Grouper](https://github.com/SamyBenchaar/Tab-auto-grouping): AI tab organiser
Chrome extension (Manifest V3) that groups open tabs by context using Gemini on Vertex AI, through a Node.js API on Cloud Run with Google sign-in and per-user daily quotas. Built with Google Developer Group on Campus.
