### 🧠 [AlphaAI](https://github.com/SamyBenchaar/Datathon2026): verifiable AI for investors
*PolyFinances Datathon 2026 × National Bank × AWS. Built end to end in 36 hours with a team.*

A personalised financial-news filter that explains why each headline matters to a given investor's portfolio. Every figure in an explanation is traced to code-computed evidence, and a guardrail checks each generated sentence.
